Track 1: Best Use of SerpApi
Build innovative solutions powered by real-time search data.
Leverage SerpApi's APIs to develop applications that utilize data from search engines and other online platforms. Participants can use any of SerpApi's APIs, including Web Search, Google Maps, Shopping, Travel, News, Finance, Jobs, Academic Research, and more.
Participants may also use the SerpApi Extract API to retrieve and process content directly from web pages.
Projects from any domain are eligible, provided they demonstrate a meaningful and innovative use of SerpApi's APIs.

Track 2: You.com: Build with live, cited web data
Develop intelligent applications powered by real-time web data.
Build an AI-powered agent, application, or integration using You.com APIs to retrieve live information from the web and deliver reliable, citation-backed responses.

Potential applications include AI research assistants, intelligent search tools, data-driven agents, knowledge platforms, and other innovative solutions combining artificial intelligence with live web information.
